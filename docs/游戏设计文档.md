# 三消宝可梦 (Match-3 Monster Adventure)

## 游戏概述

**一句话描述：** 三消 + 怪物收集养成 + 冒险闯关 = 三消宝可梦

**目标平台：** 微信小游戏（手机竖屏）

**核心玩法：**
- 经典三消机制（交换相邻宝石，匹配3个或以上消除）
- 消除对应属性宝石来发动攻击
- 打败怪物后可以收服
- 收服的怪物可以编队出战、培养升级
- 冒险闯关，逐步推进

---

## 游戏设计文档

### 1. 核心系统

#### 1.1 三消战斗系统
- **棋盘：** 8×8 网格
- **宝石类型：** 5种属性 → 火🔥、水💧、草🌿、雷⚡、光✨
- **操作方式：** 滑动交换相邻宝石
- **消除规则：** 
  - 3连消除（基础伤害）
  - 4连消除（产生强化宝石，范围伤害）
  - 5连消除（产生彩虹宝石，全屏同色消除）
- **连锁反应：** 消除后宝石下落，自动匹配继续消除
- **战斗关联：** 消除的属性宝石 = 对应属性怪物的攻击

#### 1.2 怪物系统
- **属性克制：** 火 > 草 > 水 > 火，雷和光互克
- **怪物稀有度：** ⭐普通、⭐⭐稀有、⭐⭐⭐史诗、⭐⭐⭐⭐传说
- **怪物数值：**
  - HP（生命值）
  - ATK（攻击力）
  - DEF（防御力）
  - SPD（速度，影响攻击频率）
  - 属性（火/水/草/雷/光）
- **怪物技能：** 每个怪物1个主动技能，消除对应属性充能

#### 1.3 队伍系统
- **队伍规模：** 3只怪物编队
- **队长加成：** 队长怪物提供全队buff
- **属性协同：** 同属性队伍有额外加成

#### 1.4 收服系统
- **收服条件：** 战斗中对怪物造成一定伤害后，怪物血量低于阈值
- **收服概率：** 根据怪物剩余血量决定（血越少概率越高）
- **捕获道具：** 不同等级的捕获球，提高捕获率

#### 1.5 养成系统
- **升级：** 消耗经验道具提升怪物等级
- **进化：** 达到特定等级后可进化（形态变化 + 数值提升）
- **技能强化：** 消耗同名怪物碎片提升技能等级

### 2. 冒险模式

#### 2.1 关卡设计
- **章节制：** 每章10个关卡
- **关卡类型：**
  - 🎯 普通关卡（打败所有怪物）
  - 🏆 BOSS关卡（章节BOSS，有特殊机制）
  - ⭐ 精英关卡（高难度，稀有怪物）
  - 🎁 宝箱关卡（纯奖励）
- **星级评价：** 1-3星（根据回合数、剩余血量评分）
- **扫荡功能：** 3星通关后可扫荡

#### 2.2 地图结构
```
第一章：草原之旅（草属性为主）
  → 1-1 新手训练
  → 1-2 草原小径
  → 1-3 野花丛中
  → 1-4 溪流旁（引入水属性）
  → 1-5 草原霸主（BOSS：花叶兽⭐⭐）
  
第二章：烈焰山谷（火属性为主）
  → 2-1 火山口
  → ...
```

### 5. 美术风格
- **像素风 + Q版**：适合小游戏，开发成本低
- **色调：** 明亮活泼，适合休闲游戏
- **宝石设计：** 简洁明了的图标，颜色区分明显
- **怪物设计：** Q版萌系，有辨识度
